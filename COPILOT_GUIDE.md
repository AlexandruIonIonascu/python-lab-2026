# Copilot: read the suggestion, run it, explain it

GitHub Copilot is an AI assistant in the editor. It can explain code in Chat
and suggest code while you type. It can also make mistakes. You are responsible
for checking and understanding any line you accept.

## Setup

1. Check [your Copilot access](https://github.com/settings/copilot). If you have
   GitHub Education benefits, activate the student benefit. Otherwise use Copilot
   Free if available. A paid subscription is not required.
2. In Codespaces, open Extensions and find **GitHub Copilot**, publisher **GitHub**,
   or use the Copilot setup button in the editor. Sign in with your GitHub account.
3. Open Copilot Chat and choose Ask/question-answering mode if available.
   Ask for explanations and small suggestions; keep control of your edits and commands.

## Chat versus inline suggestions

Chat answers your questions. Inline suggestions appear as faded text inside the
editor. Read before accepting; Tab usually accepts and Esc rejects. If you do
not see an inline suggestion, the Chat task still lets you practise Copilot.
Plans have limits, so do not assume every model or feature is available.

## The routine for these labs

**Ask → read → choose → save → run → explain.**

Ask for one print statement or a short explanation. Accept only what you can
explain. If the suggestion adds unfamiliar code, ask for a simpler version.
Run the result and compare it with your prediction. Record the prompt, one
suggested line, your decision, and the result in LEARNING_LOG.md.
You still perform commit and push yourself.

Lab 1's first print exercises and Lab 2's first attempts at variables are done
without AI. Disable suggestions for Python from the Copilot menu for those tasks.
Do not put passwords, tokens, or personal records in prompts.

## If access is unavailable

Tell the instructor. Observe their demonstration without sharing accounts,
test a demonstrated print statement yourself, and label the log entry
“observed demonstration”. Continue Python and Git work. The instructor can
arrange a short make-up activity for individual Copilot use.
