# Help

| Problem | What to do |
| --- | --- |
| Python shows an error | Read the filename and line number; check quotes, parentheses, and variable spelling; save and rerun |
| Python shows old text | Save the file, then run the correct filename |
| Cannot find the file | Compare Explorer with the terminal's ls output |
| Python extension missing | Extensions → Python → Microsoft → Install or Enable |
| Commit button does not work | Save All, click + beside the changed files, and enter a commit message; ask for help if still blocked |
| Files appear under both Changes and Staged Changes | Save the latest edits, then click + beside the file under Changes again before committing |
| GitHub still shows old code | Source Control → … → Push, wait, and refresh the correct repository |
| Commit/Push asks for identity or reports an error | Keep the Codespace open and ask the instructor for help |
| Copilot unavailable | Ask for a demo and follow the manual fallback; label it in the log |
| Model picker offers only Auto | Follow the Auto alternative in README.md |
| Inline suggestion does not appear | Check Copilot completions are enabled for Python; ask for help or write the line manually |
| Codespaces cannot start | Check existing Codespaces and ask the instructor about account limits |
| Classroom 50 says Not a member yet | Ask instructor to add your GitHub username and accept the organization invitation |
| Instructor cannot open private template copy | Check the collaborator invitation was accepted |
