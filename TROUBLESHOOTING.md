# Quick help

| Problem | What to try |
| --- | --- |
| Cannot find Python: Select Interpreter | Install/enable Microsoft Python in the Codespace |
| `python: command not found` | Check you are in Codespaces and setup finished; ask the instructor |
| Python cannot find the file | Run `pwd` and `ls`; check the filename and project folder |
| Output still shows the old message | Save the correct file and run it again |
| Python reports a syntax/name error | Check quotation marks, parentheses, and exact variable spelling; ask for help |
| The program waits after a question | Type your answer in the terminal and press Enter |
| `nothing to commit` | Save All, run `git status`, and check you selected the changed file |
| Git requests your identity | With instructor help, set `git config user.name "Your name"` and `git config user.email "YOUR_GITHUB_EMAIL"` using your own GitHub details |
| Push fails | Check your account and `git remote -v`; ask the instructor before trying other Git commands |
| Instructor cannot open the private repository | Check the username you invited and whether the invitation was accepted |
| Copilot is unavailable | Tell the instructor and use the observed demonstration option |
| Codespaces cannot start | Tell the instructor; do not buy resources |

If Codespaces is unavailable, the instructor can help set up Python, Git, VS Code,
and the Microsoft Python extension locally, then clone your own repository.
The command may be `python3` on macOS/Linux or `py` on Windows. Save, commit,
push, and checking the browser still apply. You can complete the Python tasks
without Copilot, then do a short Copilot make-up activity.
