# Help when something goes wrong

Return to [README.md](README.md) after resolving the problem.

| Symptom | What to check |
| --- | --- |
| GitHub shows the old code | Save All, inspect git status, commit, push, then refresh the right repository |
| Python runs old text | Save the file and rerun it; old terminal output stays unchanged |
| Cannot find the Python file | Use pwd and ls; match the filename in Explorer, including .py |
| Syntax error | Read the filename/line number and check quotes and parentheses |
| NameError | Define the variable first and check spelling/capitalization |
| Python extension missing | Extensions → Python → Microsoft → Install or Enable; select interpreter |
| Copilot missing or limit reached | Check Microsoft Copilot extensions and sign-in; ask the instructor for a demo/follow-up |
| Only Auto is available | Expected for Free/Student Chat plans; follow the Auto alternative |
| No inline suggestion | Check Copilot completions are enabled for Python; complete manually and label it |
| Push rejected or authentication error | Keep the Codespace open and ask for help; do not force push |
| Codespace quota reached | Inspect existing Codespaces; preserve work and stop unused running ones; ask instructor about access |
| Classroom 50 says Not a member yet | Ask instructor to add your GitHub username to the roster; accept the invitation |
| Instructor cannot open private copy | Template route: check collaborator invitation was accepted |
