# Getting started with GitHub, Codespaces, and Copilot

**Two 90-minute labs • beginner level • individual work • taught in English**

These labs focus on learning your working environment and submitting your work.
You will finish with short Python exercises using `print` and variables.

## Start here

1. Create a GitHub account and verify your email before the first session.
2. Open this template → **Use this template → Create a new repository**.
3. Choose your own account as Owner. Name your copy `python-lab-2026-CODE`, using
   the student code provided by your instructor. Select **Private**.
4. In your copy, open **Settings → Collaborators → Add people** and invite
   `AlexandruIonIonascu`. Your instructor needs to accept the invitation.
5. In **your own copy**, choose **Code → Codespaces → Create codespace on main**.
6. Follow [Lab 1](LAB_01.md). Reopen the same Codespace for [Lab 2](LAB_02.md).

Your instructor will announce the deadlines and the LMS/form used for submission.
Do not open a Codespace directly from the instructor's template; create your own
repository first. Use the repository URL when submitting, not the Codespace URL.

## What you will practise

| Lab | Main focus | Python at the end |
| --- | --- | --- |
| 1 | Your repository, Codespaces, terminal, Python extension, commit and push | A few `print` statements |
| 2 | Resume your work, repeat commit/push, use and explain Copilot suggestions | `print`, text variables, changing a value; optional text input |

The reference guides are there when you need them: [GitHub](GITHUB_GUIDE.md),
[Codespaces](CODESPACES_GUIDE.md), [Copilot](COPILOT_GUIDE.md), and
[Python](PYTHON_GUIDE.md). You do not need to read all guides before starting.
For problems, see [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

`.py` files contain Python code. `.md` files contain readable instructions.
The `.devcontainer/` folder prepares Python in Codespaces. `.github/` contains
guidance for Copilot. `.gitignore` excludes generated files. You do not edit
these configuration files during the labs.

## Remember these four actions

**Save:** store your edit in the Codespace. **Run:** execute your program.
**Commit:** record your change in Git. **Push:** send your commits to GitHub.
Your instructor can read the pushed version once they have repository access.
