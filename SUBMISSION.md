# Submit your work after each lab

Your instructor provides the deadlines and submission location in the LMS.

1. **Save All** and run the file you changed.
2. Use the lab's `git add`, `git commit`, and `git push` commands.
3. Open your own repository on GitHub and read the changed files.
4. Open the latest commit above the file list and copy its link.
5. Submit your student code, repository URL, and latest commit link in the LMS/form.
6. Confirm that the instructor has accepted your private repository invitation.
7. Stop your Codespace after the browser check.

| Stage | Files to submit |
| --- | --- |
| Lab 1 | `lab1.py` and the Lab 1 part of `LEARNING_LOG.md` |
| Lab 2 | Updated `lab1.py`, completed `lab2.py`, and completed `LEARNING_LOG.md` |

You make two small commits of your own in each lab. The template's initial
commit does not count. The instructor checks the changes and asks you to show
the workflow, rather than grading by commit count alone.
If you did the optional input task, include `input_practice.py` as well.

Example submission fields:

```text
Student code:
Stage: Lab 1 / Lab 2
Repository URL:
Latest commit URL:
Instructor access: confirmed / invitation pending
Any problem encountered:
```

Do not submit the Codespace link or only screenshots. Your instructor needs
the repository and commit link to read your code. If push fails, report the
problem and submit your progress by the deadline; do not claim it was pushed.
